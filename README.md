## The review

> Waited 45 minutes, server brought the weekend's leftovers cold, then charged me a full week. One star. Never coming back Monday.

- **Characters:** 128 (limit 180)

## Run

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT`), validating it first: one line, non-blank, no control characters, at most 25 words and 180 characters, and it reads the file back to confirm what landed is exactly what was validated.
